2 · Agent workflow flow

3 · Walk-through

  1. IngestOn startup the loader validates all CSVs, builds SQLite tables, the entity-resolved knowledge graph, and a vector index of every free-text field (S1 S2 S3 M1 M3).
  2. IntakePresenter picks initiatives (or uploads a Jira-style CSV). FastAPI starts a run and streams agent events over SSE to the pipeline screen.
  3. Analyse + discoverAnalyser extracts systems; Discovery runs three evidence tools in parallel — explicit text, GitHub code deps, ServiceNow ownership.
  4. VerifyThe critic rejects any edge without a citable source; weak ones go back for a narrower re-query. Each edge is tagged documented-in-Jira vs newly inferred.
  5. Sequence + riskGraph algorithms order work and find cycles; DRI rules score blockers using capacity, ownership, controls (Archer mock) and history.
  6. ReviewResults screen + reasoning drawer show the chain and sources. Reviewer challenges or approves; challenge re-runs sequencing with the new constraint.
  7. ExportApproved items export as Jira link/sequence-note proposals and an audit JSON — never written to Jira automatically.
